# Seasonal Agriculture Performance Analysis
A data analytics project analyzing agricultural performance across seasons (Kharif, Rabi, Zaid) 
using a dataset of 4,000 farm records across 8 Indian states and 8 crops.

## Objective
To identify seasonal patterns, trends, and relationships in crop yield, resource usage, and 
economic performance, and provide data-driven recommendations for better agricultural planning.

## Dataset
`seasonal_agriculture_performance_dataset.csv` — contains environmental conditions (rainfall, 
temperature, soil health), resource usage (fertilizer, irrigation, water), and economic outcomes 
(cost, revenue, profit) for farms across three seasons.

## Key Analysis
- Data cleaning (missing values, duplicates, feature engineering)
- Seasonal comparison of yield, rainfall, and temperature
- Resource usage and water efficiency by season
- Economic performance and loss analysis
- Correlation between environmental factors and yield/profit
- State-wise and crop-wise seasonal comparison

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, VS Code

## Key Findings
- Kharif season shows the highest rainfall and yield; Zaid shows the lowest water efficiency
- Nearly half of all farms report a net loss, regardless of season
- Yield correlates positively with rainfall and soil moisture, negatively with disease/pest risk

## Files
- `Seasonal_Agriculture_Performance_Analysis.ipynb` — full analysis notebook
- `seasonal_agriculture_performance_dataset.csv` — dataset used
